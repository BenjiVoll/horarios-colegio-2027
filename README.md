# Sistema de Gestión de Horarios Escolares

Aplicación web para la planificación académica y asignación de horarios escolares (1º a 8º Básico), validación de topones de profesores en tiempo real, sábana general de horarios y cuadro de carga horaria docente (Horas Lectivas, SEP y No Lectivas 65/35).

## Estructura del Proyecto
- `index.html` — Interfaz principal de la aplicación
- `styles.css` — Estilos visuales y formato de impresión PDF
- `app.js` — Motor de validación de topones, autocompletado y gestión por año escolar
